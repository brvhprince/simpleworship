# SimpleWorship's website

The page at <https://brvhprince.github.io/simpleworship/>: plain HTML, CSS
and JavaScript, with nothing to build. It is published by
`.github/workflows/website.yml` whenever this folder changes on `main`.

To work on it, serve the folder and open it in a browser:

```sh
cd website && python3 -m http.server 4173
```

- `index.html`: the page.
- `style.css`: a projection booth: the app's own preview blue and live red.
- `main.js`: the hero's live screen (it answers the app's keys), the Listen
  demo, the feature tabs, and download links for the newest release.

Everything shown on its screens is public domain ("Amazing Grace" and the
King James Version).
