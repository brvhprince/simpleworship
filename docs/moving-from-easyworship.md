# Moving from EasyWorship

SimpleWorship imports your EasyWorship 6 or 7 **songs** and **Bibles**.
EasyWorship's own files are only read, never changed, so you can keep using
EasyWorship while you try SimpleWorship.

## On the same Windows computer

Start SimpleWorship. The first time it runs, it looks for EasyWorship and
offers to bring your library across. Choose **Review and Import**, check the
list, and press **Import**.

You can do this again at any time from **File › Import from Other Software…**
or the **Import…** button on the Songs tab.

## From a Windows computer to a Mac or Linux

EasyWorship only runs on Windows, so copy its folders over first (a USB
stick works well). These are the usual locations; yours may differ if
EasyWorship was installed elsewhere or uses another profile name.

| What    | Usually, on the Windows computer                                               |
| ------- | ------------------------------------------------------------------------------ |
| Songs   | `C:\Users\Public\Documents\Softouch\EasyWorship\Default\v6.1\Databases\Data`  |
| Bibles  | `C:\ProgramData\Softouch\EasyWorship\Plugins\Bibles` (files ending in `.ewb`) |

`ProgramData` is hidden: type the path into File Explorer's address bar.

Put both folders anywhere on the new computer, then in SimpleWorship choose
**File › Import from Other Software… › Choose Folder…** and pick the folder
that contains them. SimpleWorship finds the song library and the Bibles
inside, wherever they are.

## What comes across

- **Songs:** title, author, copyright (with the administrator), CCLI number
  and lyrics. Lines such as "Verse 1" or "Chorus" become sections, so the
  V1, C… jump shortcuts work straight away. Songs already in your library
  are recognised and left out.
- **Bibles:** every `.ewb` Bible, including ones made by hand. Check the
  short names in the review step: a Bible copied from another may still
  carry the other's name.

Not imported (yet): EasyWorship schedules, themes, backgrounds and media.
Bibles you buy from EasyWorship are licensed to you; only import Bibles
you are allowed to use.
